# สไปรต์โคลนตามอาชีพ

ภาพอย่างเดียว ไม่ได้ต่อเข้าเอนจินจำลอง และไม่ได้เปลี่ยนกฎอาชีพ

โคลนตัวเดียวกันห้าชุด เดินสี่ทิศ แถวละสี่เฟรม

| แถว | ทิศ |
| --- | --- |
| 1 | ลง `down` |
| 2 | ซ้าย `left` |
| 3 | ขวา `right` |
| 4 | หันหลัง `up` |

ยืนใช้เฟรม `1` ของทิศที่หัน เดินใช้เฟรม `1`–`4`

ไบต์ของภาพเก็บเป็นข้อความ base64 คู่กับชื่อเดิม เติม `.b64` เช่น `jobs/forager/down-1.png.b64` หน้าลานถอดเองตอนเปิด ถ้าต้องการไฟล์ PNG/GIF จริงให้รัน

```bash
python3 scripts/materialize-clone-sprites.py
```

ไฟล์จะถูกเขียนข้างๆ แหล่ง base64 และไม่ต้องคอมมิตกลับถ้าไม่ได้ตั้งใจแก้ภาพ

| อาชีพ | ไฟล์ | ของที่ติดตัว | จุดในลาน |
| --- | --- | --- | --- |
| ผู้หาอาหาร | `forager` | ตะกร้าเบอร์รี่ สายเขียว | พุ่มเบอร์รี่ |
| คนตัดไม้ | `woodcutter` | ขวานสั้น ปลอกแขนหนัง | ท่อนไม้ |
| คนขุดหิน | `miner` | อีเต้อสั้น ผ้าคอสีเทา | หินแม่น้ำ |
| ช่างก่อสร้าง | `builder` | ค้อน ผ้ากันเปื้อน ถุงตะปู | บ้านมุงจาก |
| นักผจญภัย | `adventurer` | ย่ามและผ้าห่มม้วน ไม่มีอาวุธ | ไม่มี |

นักผจญภัยเป็นภาพนักสำรวจ ไม่ใช่นักสู้ ไม่มีดาบ คันธนู หรือผ้าคลุม

ชีตทั้งแผ่น: `jobs/{อาชีพ}-sheet.png` รวม `clone-walk.png`, `clone-idle.png`, `props-sheet.png`, `house.png`

หน้าลองเดินอยู่ที่ [`art/yard.html`](../yard.html) กด A ไปซ้ายของจอ D ไปขวา ชุดเริ่มต้นคือผู้หาอาหาร
