# WM4.2 — Food Regeneration Ecology Impact Report

Before any ecology-sensitive regeneration formula is allowed, WM4.2 measures the evidence distribution.

It reports food-node regeneration potential:
- minimum
- P25
- median
- P75
- maximum
- average
- depleted node count
- empty node count

Nodes are classified only relative to the observed distribution:
- low: below P25
- middle: P25–P75
- high: above P75

## Deliberate non-decision

WM4.2 defines **no candidate unit amount**.

The authoritative policy remains:
- +3 food every 120 ticks
- capped at node.max

This prevents an arbitrary ecology multiplier from being smuggled into gameplay before the actual impact distribution is known.

A later gate may use this evidence to design and verify a bounded formula.
