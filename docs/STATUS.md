# Simclone — Generation Continuity 0.3.4

Implementation: 0.3.4 engine/UI over Survival Core, autonomous birth, stage gameplay and age death. Save schema: 0.2.0; legacy 0.1.0 migration and browser key are unchanged. Deployment is a separate exact-commit gate, not implied by this file.

## Current changes

Global autonomous birth gap is four simulated years, with a four-year same-parent cooldown. Costs and survival reserves are unchanged. The purpose is to spread age cohorts; it does not retroactively repair the ages of existing colonies.

All runtime module pins, UI/version assertions and startup checks are aligned. The birth panel reads the real BIRTH_RULES interval and the Clone preview distinguishes manual adult creation from autonomous child birth.

The strengthened continuity proof runs five unmodified fresh worlds for 120 years with real aging/death and zero manual CLONE commands. It checks productive living descendants after all initial people die, identity/inheritance, dead-owner reservation cleanup, three checkpoint continuations and single/batched stepping equivalence. Final results are in [the retained verification report](verification/lifecycle-0.3.4.json); the exact candidate and main workflows are also mandatory.

A save generated by the actual previous 0.3.3 engine is retained with source/hash provenance and is tested for byte-preserving restoration and deterministic continuation.

## Limits

The historical Survival Core 100-day fixture caps biological ages below age-death threshold. It is not the continuity proof. Offline Chromium uses a Storage test double; native browser persistence and physical Android performance are UNKNOWN. The fresh-world proof does not guarantee rescue of already-collapsed or all-elder legacy saves. Agent-history cap remains 200, so unlimited-time population continuity is not established.

Mentor teaching, cultural knowledge archive, social relationships, factions and replay are not implemented. V1.0 is not claimed.
