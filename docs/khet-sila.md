# เขตศิลา

กฎอาชีพและมอนสเตอร์ที่ยืนแยกจากเอนจิน Simclone โมดูลนี้อ่านและคำนวณได้เอง ไม่เขียนสถานะโลก และไม่แทนที่ skill XP ของซิม

มอนสเตอร์เป็นศัตรูในโซน ไม่มีการเลี้ยง คอก หรือผสมพันธุ์ สูตรพลังหกค่าใช้กับตัวละครและศัตรูในโมดูลนี้เท่านั้น

ผู้เรียกคนเดียวที่อนุมัติคือแผง `src/khet-panel.mjs` ตาม `docs/KHET_PANEL_CALLER_SUCCESS_CONTRACT.md` เอนจินไม่นำเข้าโมดูลนี้ และยังไม่ merge

เงาการเจอศัตรูอยู่ที่ `docs/KHET_WORLD_LINK_SUCCESS_CONTRACT.md`

ทดสอบรวมอยู่ใน `npm test` ผ่าน `tests/khet-sila.test.mjs`
