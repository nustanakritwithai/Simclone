# เขตศิลา

กฎอาชีพและมอนสเตอร์ที่ยืนแยกจากเอนจิน Simclone โมดูลนี้อ่านและคำนวณได้เอง ไม่เขียนสถานะโลก ไม่ถูกเรียกจาก `index.html` และไม่แทนที่ skill XP ของซิม

มอนสเตอร์เป็นศัตรูในโซน ไม่มีการเลี้ยง คอก หรือผสมพันธุ์ สูตรพลังหกค่าใช้กับตัวละครและศัตรูในโมดูลนี้เท่านั้น

ยังไม่ต่อเข้าเกมที่เล่นอยู่ และยังไม่ merge จนกว่าจะมีสัญญาว่าจะเชื่อมกับโลกอย่างไร

ทดสอบรวมอยู่ใน `npm test` ผ่าน `tests/khet-sila.test.mjs`
