# WS2 — Dynamic Hydrology

Stack: `K6 -> WorldSim Full Map (#29) -> WS2 Hydrology`.

Source contract adapted from Living World Physics Simulator 20.9.4:
- fixed deterministic hydrology steps
- four-neighbor downhill surface flow
- surface water / soil moisture / groundwater reservoirs
- terrain-dependent absorption and evaporation
- groundwater recharge
- flood threshold
- explicit conservation accounting

## Source-of-truth rule

No duplicate water reservoir is introduced.

`worldMap.surfaceWater`, `worldMap.soilMoisture`, and `worldMap.groundwater` are the only modeled water stores.

`worldHydrology` contains scheduler/accounting metadata only.

Rainfall is currently an explicit external input from the static climate fields generated by WM1. Evaporation is an explicit external output until WS3 couples evaporation into atmospheric moisture.

## Not yet gameplay authority

Flood state does not yet block agent movement or alter productivity. That will be a separate authority gate after hydrology determinism/conservation is proven.
