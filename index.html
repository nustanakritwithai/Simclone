1. Game Pillars

หัวใจของเกมไม่ใช่จำนวน NPC แต่คือความต่อเนื่องของเหตุและผลข้ามคน ข้ามกลุ่ม และข้าม Generation

🧠

5. AI / AI CPU Strategy

System 0

Deterministic Execution

movement, inventory, skill execution, path step, resource transfer — สิ่งที่รู้แน่แล้วต้องไม่ใช้ LLM

System 1

CPU Decision

candidate scoring, planning, search, priority และ policy ที่คำนวณได้เร็วและ reproduce ได้

System 2

LLM Novelty

ใช้เมื่อเกิดสิ่งใหม่ คลุมเครือ ต้องสะท้อนเหตุผล หรือเสนอ skill/rule ใหม่ แล้วต้อง verify ก่อนใช้งานจริง

หลักการ Reasoning Compilation

อย่า generate ถ้าเลือกได้ • อย่า reasoning ถ้าคำนวณได้ • AI proposal ที่ผ่าน verification แล้วควรไหลลงเป็น knowledge → deterministic rule/skill

7. Systems หลัง V1.0

👥 Social Brain

  • Trust / Affinity / Respect / Fear / Debt
  • Friend / Rival / Family / Mentor / Student
  • Relationship เปลี่ยนจากเหตุการณ์จริง

🏳 Faction

  • สร้าง / ยุบ / แตก / รวม
  • Leader succession
  • Goal, rules, resources, knowledge, territory

💱 Economy

  • Shared resource → specialization
  • Production / processing
  • Barter / trade / scarcity / logistics

⚔ Conflict

  • เริ่มจากภัยสิ่งแวดล้อมและสัตว์
  • Conflict ต้องมีเหตุ

🧪 Discovery

  • Experience → Hypothesis → Experiment
  • Outcome → Verification
  • ความรู้ผิดแพร่ได้และถูกพิสูจน์ผิดได้

📚 Culture

  • เมืองต่างกันมี technology ต่างกัน
  • Knowledge transfer เมื่อวัฒนธรรมพบกัน

8. Next Build Order

ลำดับพัฒนา

  1. สร้าง Simulation Skeleton + deterministic tick
  2. ปิด Survival / Lifecycle / Skill / Knowledge baseline
  3. ล็อก regression เป็น V0.6.4
  4. ทำ V0.7 Decision Brain + Decision Trace UI
  5. ทำ V0.8 Perception + local knowledge
  6. ทำ V0.9 Spatial map + pathfinding
  7. รัน V1.0 100-day proof
  8. ค่อยเพิ่ม Social / Faction / Economy / Conflict
  9. ต่อ Culture / Discovery / Evolution
  10. เพิ่ม AI Brain + AI CPU + Reasoning Compilation
  11. ขยาย V2.0 หลายเมือง

สิ่งที่ยังไม่ควรทำก่อน V1.0

  • ไม่ทำ 3D ใหญ่ก่อน Decision/Perception ผ่าน
  • ไม่เพิ่มหลายเมืองก่อนโลกเดียวอยู่รอด 100 วัน
  • ไม่เรียก LLM ทุก Agent ทุก tick
  • ไม่ทำสงครามซับซ้อนก่อน Social/Faction เสถียร
  • ไม่ rewrite engine เพื่อแก้ UI
  • UI แสดงค่าได้ ≠ ระบบผ่าน ต้องมี deterministic test

9. Development Rules

Verify → Improve → Prove

  • กำหนด Success Contract / Definition of Done ก่อนลงมือ
  • ผลลัพธ์แรกเป็น candidate ไม่ใช่คำตอบสุดท้าย
  • Verification แยก SAT / VIOL / UNKNOWN
  • ทุก milestone มี deterministic test + long-run test
  • เก็บ seed + event log เพื่อ reproduce bug

Performance Strategy

  • Agent ไกลใช้ simulation fidelity ต่ำลง
  • Known skill ใช้ deterministic code
  • Decision scoring ทำ batch/CPU
  • Perception จำกัดพื้นที่
  • Memory retrieval เฉพาะที่เกี่ยวข้อง
  • LLM มี budget และ cooldown
Final Product Vision

กลับมาอีกหลายร้อยปี แล้วโลกยังมีเรื่องของมันเอง

ผู้เล่นสามารถเปิดโลกที่ปล่อย simulation ทิ้งไว้ แล้วพบว่า Clone รุ่นหลังสร้างเมือง กลุ่ม ความรู้ เทคโนโลยี และเรื่องเล่าที่ไม่ได้ถูก script ตั้งแต่แรก หัวใจคือ: คนหนึ่งพบสิ่งใหม่ → เรียนรู้ → ถ่ายทอด → คนรุ่นหลังดัดแปลง → สังคมเปลี่ยน → เหตุการณ์กลายเป็นประวัติศาสตร์
